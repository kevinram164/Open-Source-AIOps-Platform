# AIOps Console

React SPA for IBM-style demos: **Ask** (Chat API) · Incidents · Remediations (approve/execute).

## Local

```bash
cd components/aiops-console
npm install
npm run dev
# proxy assumes incident :8080 and remediation :8081
```

## OCP

Route: `https://aiops-console-aiops-core.apps.ocp01.npd.co`  
Jenkins: `BUILD_TARGET=aiops-console`
